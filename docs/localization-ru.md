# Русификация LocalMiniDrama (экспериментальная)

В этой ветке добавлен переключатель интерфейса **Русский / English / 中文**. Язык по умолчанию — русский; выбранный язык сохраняется между запусками.

## Как скачать готовую Windows-версию

1. Откройте вкладку **[Actions](https://github.com/Darksider317/LocalMiniDrama/actions/workflows/localization-build.yml)** в своём форке.
2. Выберите последнее успешное выполнение **Russian interface - Windows build**.
3. Внизу страницы откройте раздел **Artifacts**, скачайте `LocalMiniDrama-RU-Windows`.
4. Распакуйте ZIP и запустите `LocalMiniDrama Setup ...exe` (установщик) либо `LocalMiniDrama ...exe` (портативная версия).

Если сборка не стартует, включите GitHub Actions в настройках форка и запустите workflow вручную через **Run workflow**, выбрав ветку `feat/russian-interface`.

Переключатель языка находится **слева внизу** на каждом экране.

## Что сделано

- Общий выбор языка для фронтенда; сохраняется в `localStorage`.
- Локализация стандартных элементов Element Plus (системные кнопки и поля).
- Словарь русских и английских текстов для стартового экрана, управления сериалом, раскадровки, холста и части настроек ИИ.
- Адаптер для старых компонентов, где китайские строки пока прописаны непосредственно в шаблонах.
- Тесты и сборка Windows-приложения через GitHub Actions.

## Ограничения

**Это первая версия русификации, а не полностью переведённое приложение.** В сложных окнах создания видео, подсказках и настройках провайдеров часть китайских текстов ещё остаётся. Неизвестные фразы сохраняются на китайском; тексты, написанные пользователем, переводить не нужно.

Настройка меняет **язык интерфейса**, а не язык генерируемых ИИ сценариев и промптов. API-ключи и настройки поставщиков не меняются.

## Для разработки

```powershell
cd frontweb
npm ci
node --test test/*.test.js
npm run build
```

При запуске исходников продолжайте использовать штатный `run_dev.bat` или инструкции из `docs/quickstart.md`.

Чтобы добавить перевод, измените `frontweb/src/localization/translations.js`. При создании новых компонентов предпочтительно использовать функцию `translate()` напрямую: адаптер DOM предназначен для ранее существовавших китайских страниц.
